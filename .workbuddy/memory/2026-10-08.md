## 图片轮播 · 六问定稿（用户拍板，落成 `.planning/design/image-carousel-design.html`）

1. **独立文件夹**：`imageFolderPath` 与视频目录并存，窗口级来源切换（页签行右侧「壁纸来源 视频|图片」，SlideSegmented 中性）；播放模式/轮换间隔**共用一份**，路径/计数/最后项各自独立。
2. **判定口径 = 总像素量**：`宽×高 ≥ 阈值`。1080P=2,073,600 / 2K=**2560×1440=3,686,400**（弃 DCI 2048×1080，只比 1080P 高 6.6%）/ 4K=8,294,400。已知取舍：全景图 8000×1200 过 4K 但只有 1200 高。
3. **三格计数**：图片总数(ink2) / 将参与轮播(恒 brandText，=用户说的「实际使用量」) / 低于档位(非零 brandText、零 ink3)。标识 `image-total/inuse/filtered`。
4. **图片适配**：Windows/macOS 默认都是「填充 Fill」→ Pic 默认同款；收 填充/适应/居中/平铺，不收 拉伸(变形)；留边由「留边处」行接管（模糊铺底/纯色/桌面背景色），仅适应/居中可用。**store 存 `imageMinPixels` 绝对值而非档位下标**。
5. **格式白名单**：jpg/jpeg/png/heic/webp；不收 GIF（动图会混回视频语义）。陷阱：像素尺寸必须取向校正后的值（HEIC EXIF）；解码失败要单独计数。
6. **轮换间隔与视频同一套**（rotationChoicesMinutes 原样复用，最短 5 分钟是既有属性）。

空态 4 变体：未配置 / 目录没了 / 0 张受支持图片 / 有图但都不过档（由**计数**消歧，不改 `LibraryState`）；均带跨源兜底按钮「改用视频壁纸」(`image-switch-to-video`)。

## 「怎么控制用视频还是图片」—— 切换机制定稿（实现层，非 UI 稿）

已核清现状：`SettingsStore` 只有一个来源键 `sourceFolder`；`WallpaperWindow` 只有 `AVPlayerLayer`（放不了静图）；
首启询问走 `FolderRequestPolicy.shouldRequestFolder(sourceFolder:)`；扫描唯一入口是 AppDelegate 的 `rescanAndApply()`。

- **新增键**：`wallpaperKind: WallpaperKind {video,image}`（UserDefaults `wallpaperKind`，读不到 → .video，老用户零迁移）、
  `imageFolderPath`、`imageMinPixels`（**存绝对值**：2073600/3686400/8294400，不存档位下标）、`imageFit`、续播加一对 `lastImagePath`（
  不加会让图片 loopSingle 复用 `lastPlayedPath`，按 path 匹配不到 → 静默从第一条开始，不崩但不可解释）。
- **共用**：playMode / rotationInterval / pauseOnBattery / launchAtLogin（节奏与让路与媒体类型无关）。
  **各一套**：目录、续播路径、筛选阈值、三格计数。
- **切换动作链（一个函数，写在 AppDelegate）**：写 kind + persist → pause + router.stop() → 换渲染层 →
  `library.invalidateCache()` → `rescanAndApply()`（同一条扫描路径，不写第二份）。
  `resolvedFolderURL()` → `resolvedFolderURL(for:)`；首启询问按当前 kind 的目录判。
- **渲染层**：给 WallpaperWindow 加常驻 `imageLayer: CALayer`（contents 放 CGImage），两层按 kind 切 `isHidden`；
  反复 add/removeSublayer 会与 `HostView.layout()`（现按 videoLayer 铺满）打架。解码放后台，主线程只赋值。
- **扫描**：新增 `ImageLibrary.scan(folder:)` → `ImageItem{url,pixelWidth,pixelHeight}`，像素尺寸取**方向校正后**值（HEIC EXIF），

- **边界**：切到图片但目录没配 → 停 `.folderUnconfigured`，**不自动回退视频**，给「改用视频壁纸」兜底；

## 图片轮播 · 第二刀：渲染层 + 轮换内核 URL 化 + 装配闭环（用户「要睡了，自主开发」后继续）

**新增文件**
- `Sources/PicCore/System/ImageFitGeometry.swift`：图片落位纯值计算（零 AppKit/CoreGraphics，照
  `FullscreenGeometry` 风格），输出**左上原点**矩形；`fill` 取 max、`fit` 取 min、`center` 取 1、
  `tile` 返回原始尺寸一块砖（不缩放不居中 —— 缩放的砖露接缝、居中的砖错位半块）。8 个单测。
- `Sources/PicCore/Render/WallpaperImageLayer.swift`：**四种适配全部自己画，不用 contentsGravity**
  （tile 没有对应 gravity，两套机制并存会让「换适配」变成换绘制路径）。draw 里按
  `isGeometryFlipped` 决定是否翻转 —— 不能假定宿主视图的 flipped 状态。

  6 个单测（含「两个 router 争抢同一个 onAdvance」的接管用例）。
