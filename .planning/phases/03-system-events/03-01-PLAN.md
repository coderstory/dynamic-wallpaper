    ```swift
    public struct LockSignalNames: Sendable, Equatable {
        public var locked: String
        public var unlocked: String
        public static let system = LockSignalNames(
            locked: "com.apple.screenIsLocked", unlocked: "com.apple.screenIsUnlocked")
    }

    @MainActor public final class LockWatcher {
        public private(set) var isRunning = false
        public init(center: DistributedNotificationCenter = .default(),
                    names: LockSignalNames = .system)
        public func start(onChange: @escaping (Bool) -> Void)   // Bool = 是否锁屏

        public func currentLockState() -> Bool                  // 读 CGSessionCopyCurrentDictionary()

    ```

    - `center` 与 `names` **都是注入参数**。理由写在文件头：真实通知 `com.apple.screenIsLocked` 由别的进程投递，用它做自测会污染整机（同机的其它壁纸 app 会一起暂停）。测试与探针一律注入 `DistributedNotificationCenter()` + 自有前缀名。

    - `currentLockState()` 读 `CGSessionCopyCurrentDictionary()` 的 `CGSSessionScreenIsLocked` 键（Phase 1 已实测该键存在，14 键表里第 1 个），返回 `Bool`。**它读不到/键缺失时返回 `false` 并且什么都不打** —— 读不到与「没锁」是两件事，不要在这里编数字。
