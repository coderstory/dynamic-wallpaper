    **`Sources/PicCore/System/PowerWatcher.swift`（新建）** ——

    ```swift
    /// 判定纯函数：开关关时电源信号一律不产生 hold（D-11 / PAUSE-05）。
    public enum BatteryHoldPolicy {
        public static func shouldHold(isOnBattery: Bool, pauseOnBatteryEnabled: Bool) -> Bool {
            isOnBattery && pauseOnBatteryEnabled
        }
    }

    @MainActor public final class PowerWatcher {
        public func start(onChange: @escaping (Bool) -> Void)   // Bool = isOnBattery
        public func stop()
        public static func currentIsOnBattery() -> Bool
    }
    ```

    - `currentIsOnBattery()` 的读法：`IOPSCopyPowerSourcesInfo()` → 第一个 `CFTypeRef` → `IOPSGetPowerSourceDescription` → 字典键 `"AC Power"`（`kIOPSPowerSourceStateKey`）取 `CFBoolean` 值；**值为真 = 在 AC 上**（不是电池），所以 `isOnBattery = !acPower`。整条链任一步返回空 → 返回 `false` 并**不区分「读不到」与「在电池上」**这一点必须写进文件头注释并如实上报：读法失败时 `start` 立刻打一行 `POWER_READ_FAILED=1`，不允许静默当成 `false` 当成「在电池上」而误暂停。
    - **事件驱动**：`IOPSNotificationCreateRunLoopSource` 挂到 `RunLoop.main`，电源状态变化时回调 → `onChange(currentIsOnBattery())`。**禁止**用 `Timer` 轮询 `pmset` 或 `IOKit`（D-01）。`stop()` 里 `CFRelease` 掉 run loop source 与 info 句柄，否则常驻泄漏（Pitfall 4）。

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| IOKit 电源状态 → 产品 | `IOPSCopyPowerSourcesInfo` 报的是**整机供电状态**；据此自动暂停播放，是用户可见的行为改变 |
