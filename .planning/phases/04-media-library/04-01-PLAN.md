    扫描体**逐条按这个顺序**写，顺序本身是被判据锁住的：
    1. 存在性：`FileManager.default.fileExists(atPath: folder.path)` 为 false → `throw .folderMissing`（**`folder.path`，不是 `absoluteString`**）
    2. `FileManager.default.enumerator(at: folder, includingPropertiesForKeys: [.isRegularFileKey, .isSymbolicLinkKey], options: [.skipsHiddenFiles], errorHandler: { _, err in lastError = err as NSError; return true })`；返回 nil → `throw .folderUnreadable`。
       ⚠️ `errorHandler` **必须返回 `true`**（跳过这一项、继续遍历）；返回 false 会让整个遍历提前终止 —— 那样「一个无权限子目录」就会让整次扫描少掉后面所有条目（本机实测 `chmod 000` 的子目录会触发 errorHandler，ERRPATHS=noperm）
    3. 遍历计数 `scanned += 1`；`scanned > entryCap` → `capped = true` 且 `break`（**如实上报 `skippedByEntryCap`，不静默截断**）
    4. `resourceValues` 取 `.isRegularFile == true` 且 `.isSymbolicLink != true` 才继续 —— 这一条同时挡掉「指向根外的符号链接」与「符号链接目录」。本机实测：符号链接的 `isRegularFile` 为 false、`isSymbolicLink` 为 true，所以这一步天然生效
    5. 扩展名：`allowedExtensions.contains(url.pathExtension.lowercased())`，不在 → 计入 `extensionRejected`（**不进** `acceptedByExtension`）
    6. `acceptedByExtension += 1`；再判 `url.pathComponents.contains { $0.caseInsensitiveCompare(Self.excludedDirectoryName) == .orderedSame }` → 命中则 `excludedByConverted += 1` 且 `continue`
       ⚠️ **精确匹配目录名，不是子串匹配** —— `converted-lower/keep.mp4` 必须仍被收。这条由 fixture 树专门验证
    7. 符号链接目标越界兜底：`url.resolvingSymlinksInPath().standardizedFileURL.path` 必须 `hasPrefix(rootRealPath + "/")`（`rootRealPath` 取 `folder.resolvingSymlinksInPath().standardizedFileURL.path`，末尾补 `/`），否则 `excludedByContainment += 1` 并 `continue`。
       ⚠️ 这一层与第 4 步**重复**，是故意的纵深：第 4 步依赖 `resourceValues` 的取值方式，第 7 步独立成立
