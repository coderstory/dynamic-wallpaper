## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| 并发超 2 | 一次派 3 个 agent，其中一个撞 403 被杀，残缺 work 留给别人收拾 | blocking | 主会话占 1 额度，一次只派一个子任务 |
| 转码测试进常规路径 | libvmaf 779.9% CPU；挂进 test.sh 等于每次校验烤一次机 | blocking | 转码测试只能独立脚本 + 手动调用；test.sh 只断言参数构造 |
| 裸 grep -c 主判据 | 注释里的字面量污染计数，已自伤 12 次 | blocking | 必须用 `src_count()`（4 条 `-e`） |
| no() 文案含 ok() 判据名 | 判据转红了但 `grep -c '❌ …'` 命中 0，查不到哪条 | blocking | 判据不放宽，改文案 |
| 插桩打在自己注释上 | perl 插到注释里抄的合取式字面量，代码没坏 | advisory | 改注释不改判据 |
| 编译失败冒充判据转红 | 插桩把代码写坏了编译不过，`MUTATED_RC=1` 却被当成断言失败 | advisory | 耦合点放 init 赋值体，使 RC 来自断言失败 |
| 一个数两种读法 | 回调计数与同步投递合一个计数器，可被误读（实测 0） | advisory | 拆成多行分开打点 |
| W 编号碰撞 | 03-03/03-04 撞过 -19；PLAN.md 里不同条目引用同一号 | advisory | Phase 4 从 -23 起，`uniq -d` 为 0 |

**Severity values:** `blocking` — resuming agent must pass understanding check before proceeding. `advisory` — important context, does not gate resumption.
