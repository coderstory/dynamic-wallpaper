    - `public enum TranscodeJobState: Equatable, Sendable { case pending, running, succeeded, skipped, failed(reason: String) }` —— reason 是**受控 token**（`disk_space` / `ffmpeg_unavailable` / `exit_nonzero` / `output_conflict`），不是自由文本（不给日志注入面）
    - `public struct TranscodeJob: Identifiable, Equatable, Sendable` —— `public let id: UUID` / `public let sourceURL: URL` / `public internal(set) var state: TranscodeJobState` / `public internal(set) var percent: Double?` / `public let commandDisplay: String`（入队时由 `TranscodeCommand.displayString` 算好 —— TRANS-06 的审计串从入队那一刻就存在）

    - `public func enqueue(sources: [URL])` —— 逐个建 Job（state pending，commandDisplay 先算）；已在队列里的同路径不重复入队
    - `public func run() async` —— **串行** drain，逐 job：
      1. `availability()` 为 `.unavailable` → `failed(reason: "ffmpeg_unavailable")`，**不进 runner**（防御：入口置灰之外的第二道闸）
      2. `skipDecision(source:)` 为真 → `.skipped`，不进 runner
      3. `mkdir Converted`（`FileManager.default.createDirectory(at:withIntermediateDirectories:)`，已存在不报错）
      4. `freeSpaceProvider(convertedDir)` 非 nil 且 < 源文件大小（`FileManager.default.attributesOfItem` 的 `.size`，读不到按「不拦截」处理）→ `failed(reason: "disk_space")`，不进 runner（P6）
      5. 建 job → `.running` → `onJobsChanged()`；`let status = runner.run(ffmpegPath:, arguments: TranscodeCommand.arguments(input: output: naming.temporaryURL(for:)), outputTemporaryPath:, onProgressLine: { line in Task { … } })` —— ⚠️ 进度回调里只做「攒行 → `ProgressParser.parseChunk` → `percent(snapshot: durationSeconds: await durationProvider(source))` → 更新 job.percent → `onJobsChanged()`」；duration 只在 job 开始时**取一次缓存**，不逐行取
      6. **退出判定单独一行**（变异打行尾）：`if status == 0 {` → rename `.tmp` → `.mp4`（`FileManager.default.replaceItemAt` 或 remove+moveItem，**rename 失败 → `failed(reason: "output_conflict")` 且清理 `.tmp`**）→ `.succeeded`；`else` → 删 `.tmp`（忽略删除错误）→ `failed(reason: "exit_nonzero")`
