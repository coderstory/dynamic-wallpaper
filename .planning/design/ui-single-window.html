转码不再是第二个窗口。四套都是一个窗：设置与转码共存，靠不同的切换机制分开。 下面每套画两个状态（播放页 / 转码页），你要判断的是切换方式顺不顺手。

skill 依据

结构：liquid-glass 范式（skill styles.csv 标记 swiftui|appkit 兼容，明暗双模式）—— 半透明材料只给导航层和容器，内容层保持实色清晰。这是转码并入后导航的正确做法。

ux 域：「固定元素不能随意堆叠，要预留安全间距」—— 转码队列若常驻底部，不能和状态条抢位置，各稿用不同容器隔离。

不采用：skill color 域给壁纸类产品的配色是紫粉预设（#7C3AED / #EC4899），那是网页向的，不适合原生 macOS 工具，本轮配色由 macOS 平台惯例决定。
