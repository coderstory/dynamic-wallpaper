### Wire 4 的 BLOCKER（已修，值得留档）

`TranscodeQueue` 是 `@MainActor`，`runner.run()` 无 `await`，末尾 `waitUntilExit()` 同步阻塞主 actor → **转码全程 app 冻结（含壁纸渲染）**，进度条卡 0% 后跳终值。

**为什么七道门禁全绿**：所有门都用 FakeRunner 或 `/bin/sh printf`（瞬时返回），没有一道跑过长时间进程。

**修法**：`run` 改 async + `waitUntilExit` 用 `withCheckedContinuation` 跳 `DispatchQueue.global(qos: .utility)`；`readabilityHandler = nil` + drain 保留在 await 之后。

**新门**：`TranscodeMainActorFreezeTests` 用真 runner + 慢桩（`/bin/sh -c 'printf…; sleep 0.3; …'`，约 0.9s），断言 `state == .running` 期间能读到 `percent` 变化。**已用 `git checkout` 回到旧形状验证门会红**（`DURING_RUN=0` vs 修复后 153）。

**反直觉事实**：只把方法标 `async` 但保留同步体，门**不会**红 —— 承重的是形状本身（async 函数天然离开主 actor），不是续体写法。
